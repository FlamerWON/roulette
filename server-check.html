Проверка входа и сохранения перед переносом экономики на сервер.

Только чтение и проверка. Эта страница не меняет монеты, вещи, бои или правила Firebase. Обмен ещё не включён.

03

Сохранение персонажа

Сервер прочитает только твоё сохранение и сверит предметы с каталогом версии 11. Ничего не переносится и не списывается.

Открой эту страницу на GitHub Pages, рядом с игрой и config.js. Из скачанного файла проверка не работает.

Токены не показываются и не выводятся в консоль. Краткоживущий токен передаётся обработчику по HTTPS для проверки; пароль и refresh-токен ему не отправляются.

Проверка сверяет формат сохранения, но не доказывает честность ранее полученных монет и вещей. Обмен и защита экономики ещё не включены.
